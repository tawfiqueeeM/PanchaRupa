# Factory Expansion & Building Management System

## Overview
This folder contains the master engineering expansion roadmap for PanchaRupa Virtual Tea Factory from initial single-line production (Building A) to multi-line high-capacity operations (Building B).

## Documentation
- `ADVANCE-PLAN.md`: Strategic roadmap and subproject objectives.
- `docs/expansion-plan.md`: Phased structural expansion strategy detailing spatial layouts, electrical incomer upgrades, thermal supply, and integration with the centralized Building Automation System (`projects/virtual-factory/building-automation/`).
